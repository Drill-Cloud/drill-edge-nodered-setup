
Данный репозиторий предназначен для установки системы Node-RED с предопределенными настройками на edge-компьютере

В системе Node-RED будет включена опция "Проекты", которая позволит работать с потоками на edge-компьютере через свой собственный отдельный репозиторий nodered-проекта.

На edge-компьютере необходимо:
- скачать и установить node
- скачать и установить git
- склонировать данный репозиторий в папку, доступную для любых пользователей компьтера
- выполнить

```
npm install
npm start
```

В "Проектах" добавить новый (или при переустановке использовать старый) проект с привязкой на свой собственный отдельный репозиторий nodered-проекта.
